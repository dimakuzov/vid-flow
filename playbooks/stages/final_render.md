# Stage: final_render

Оригинал на русском. Для модели: `playbooks/stages/final_render.en.md`.

## Решение: финал с репликами — MiniMax H3 Cinema по первому кадру и лицам

Кадр с одним говорящим делает MiniMax H3 в режиме референсов с ЛоРой Cinema (`final_h3_cinema`): утверждённый первый кадр — `<Picture 1>`, по картинке на персонажа даёт лицо, а движение утверждённого превью переносит текст. Видео-референса нет. Пользователь выбрал этот граф, потому что он стабильно держит качество и сходство; старый граф H3 с low-res видео как референсом (`MiniMaxH3Creator`) часто ломался и убран. Как писать текст и формат `prompt.md` — `playbooks/models/minimax_h3.md`. `prompt.md` всегда на английском.

## Варианты

| id манифеста | order | Граф | Когда |
| --- | --- | --- | --- |
| `final_heygen` | 2 | `heygen_video_i2v_api.json`, HeyGen Video 1.0 в **Comfy Cloud** (платно, ~45.3 кредита за 10 с, 5–15 с), от утверждённого первого кадра, длина превью | по умолчанию для **диалога** (в `speech.md` двое говорящих и больше); запускается только с галочкой «Разрешить платную отправку в Comfy Cloud» на этот запуск. Промпт: `playbooks/models/heygen_video.md` |

| `final_h3_cinema` | 4 | `minimax_h3_cinema_api.json`, MiniMax H3 по референсам + ЛоРа Cinema, два прохода (1 Мп, затем апскейл латента до 1.5 Мп), 24 к/с, длина превью | по умолчанию для кадра **с одним говорящим** (`speech.md`): MiniMax сам озвучивает и двигает губами |

| `final_i2v` | 10 | `wan22_i2v_sketch_turbo_api.json` | запасной: повторить эскиз Wan на новых seed |

Промпт не нужен: пользователь жмёт «Запустить». По умолчанию не бывает |
| `final_flf` | 8 | `wan22_flf_sketch_turbo_api.json`, 720×1280, 24 к/с (как `final_wan_720`), промпт утверждённого эскиза (из метаданных ролика), первый и последний кадр, длина превью | по умолчанию, если утверждённый эскиз — FLF. Последний кадр: `refs/` этого этапа, иначе самая новая картинка в `video_preview/refs/` |

Нужно для H3 Cinema: файл в `first_frame/approve/`. Утверждённое превью даёт длительность и движение, которое агент переносит в текст. Картинки персонажей — по одной на персонажа в порядке `characters/approve/`: `refs/` этого этапа, если там есть файлы, иначе лист лица персонажа (`refs/{имя}_face_sheet`, затем `*face_sheet*` в библиотеке), иначе одно лицо (`refs/{имя}_face`, затем портрет из библиотеки), иначе утверждённый персонаж; до шести. В задаче они — `<Picture 2>`, `<Picture 3>`, …

Если в `prompt.md` нет `subject_definitions ASTROCINEMAV01K2T:` (триггер ЛоРы Cinema), доска ставит эту строку первой. Если английской реплики из `speech.md` нет в `prompt.md`, H3 не запускается.

Финал Wan получает ещё одну строку в конце промпта эскиза: фон остаётся как на первом кадре, новых людей нет, сзади никто не ходит, двери и окна как есть. В 720×1280 Wan иначе додумывает детали (люди на заднем плане, открывающиеся двери). Подробно: `playbooks/models/wan_video.md`.

## Какой вариант по умолчанию

Доска смотрит на самый новый файл в `video_preview/approve/`: финал идёт за утверждённым превью. Эскиз LTX — вариант `final_ltx`, эскиз MiniMax — `final_h3_cinema` (его промпт уже в форме MiniMax), даже если реплики говорят иное. Иначе — по репликам. Конечную позу доска сама не угадывает.

| Ситуация | Вариант | Кто решает |
| --- | --- | --- |
| Утверждённый эскиз сделан LTX | `final_ltx` | доска, по умолчанию |
| Утверждённый эскиз сделан MiniMax | `final_h3_cinema` | доска, по умолчанию |
| Утверждённый эскиз — FLF (Wan, первый и последний кадр) | `final_flf` | доска, по умолчанию |
| Никто не говорит, эскиз Wan | `final_wan_720` | доска, по умолчанию |
| Говорит один | `final_h3_cinema` | доска, по умолчанию |
| Говорят двое и больше | `final_heygen` | доска, по умолчанию. Запуск только с галочкой «Разрешить платную отправку в Comfy Cloud» на этот запуск |
| Нужна конкретная конечная поза, а эскиз не FLF | `final_flf` | агент пишет `suggestedWorkflow`. Последний кадр — в `refs/` этого этапа |

Как доска узнаёт граф эскиза: в метаданных ролика (ключ `prompt`, его пишет SaveVideo) есть непустой текст ноды `398:376` / `value` — это LTX. Метаданных нет — смотрит имя файла: подстрока `_ltx` (`s01_ltx_00001_.mp4`). Имя не смотрит, если метаданные есть: файл могли переименовать. Подробно — `docs/contracts/graph-binding.md`.

Промпт финала Wan, финала LTX и промпт эскиза в задаче H3 Cinema — текст из того же ролика (нода Wan `129:93` / `text` или нода LTX `398:376` / `value`, какая есть в метаданных). Нет метаданных — `prompt.md` этапа `video_preview`, и доска дописывает пометку в `run_log.md` финала. Позже правка `prompt.md` без нового ролика в финал не попадает.

Агент, у которого выбранный вариант не из таблицы, пишет id в `suggestedWorkflow`. Доска показывает предложение и сама не переключает.

## Ещё не проверено

- Апскейл до 1080×1920 (SeedVR2) и интерполяция 16 → 32 fps (RIFE) — не в доске.
- MiniMax H3 через API MiniMax (облако) — не подключён.
- Вариант «финал от базового low-res H3-ролика» (шаблон `create_final_video_using_base_reference`): черновик описания в `playbooks/workflows/drafts/final_h3_base_reference.md`, графа и манифеста нет.

## Критерии приёмки

- Действие, композиция и конец совпадают с утверждённым превью. Финал не придумывает новых событий.
- Первый кадр совпадает с утверждённым первым кадром.
- Лица совпадают с референсами персонажей, одежда — с первым кадром.
- Нет артефактов, которые терпимы в эскизе, но не в монтаже: лишние пальцы, мерцание лица, морфинг одежды, блёстки, скачок в последних кадрах.
- Длительность совпадает с превью.
- Файл в `approve/` один на кадр. По нему наблюдение за кадром (`AGENTS.md`, «Shot watch») считает кадр готовым.
