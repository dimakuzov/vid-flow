# Stage: final_render

Оригинал на русском. Для модели: `playbooks/stages/final_render.en.md`.

## Решение: финал — MiniMax H3 по утверждённому превью

Финальный рендер делает MiniMax H3 (нода `MiniMaxH3Creator`, ComfyUI-Continuity): low-res Wan-ролик из `video_preview/approve/` — референс движения, утверждённый первый кадр — первый кадр финала, референсы персонажей — лица. Как писать текст и формат `prompt.md` — `playbooks/models/minimax_h3.md`.

## Варианты

| id манифеста | order | Граф | Когда |
| --- | --- | --- | --- |
| `final_heygen` | 2 | `heygen_video_i2v_api.json`, HeyGen Video 1.0 в **Comfy Cloud** (платно, ~45.3 кредита за 10 с, 5–15 с), от утверждённого первого кадра, длина превью | по умолчанию для **диалога** (в `speech.md` двое говорящих и больше); запускается только с галочкой «Разрешить платную отправку в Comfy Cloud» на этот запуск. Промпт: `playbooks/models/heygen_video.md` |
| `final_wan_720` | 3 | `wan22_i2v_sketch_turbo_api.json`, 720×1280, промпт и первый кадр эскиза, длина превью | по умолчанию для кадра **без реплик** |
| `final_h3_768_face` | 4 | `minimax_h3_creator_api.json`, 768, face pass | по умолчанию для кадра **с репликами** (`speech.md`): MiniMax сам озвучивает и двигает губами |
| `final_h3` | 5 | тот же граф, 1152, face pass | лица, и кадру нужно разрешение выше |
| `final_h3_768` | 6 | тот же граф, 768, без face pass | кадров без людей, мелкие лица, быстрее и легче по памяти |
| `final_i2v` | 10 | `wan22_i2v_sketch_turbo_api.json` | запасной: повторить эскиз Wan на новых seed |
| `final_flf` | 20 | `wan22_flf_sketch_turbo_api.json` | запасной, если эскиз был FLF (последний кадр — в `refs/` этого этапа) |

Нужно для H3: файл в `video_preview/approve/` и в `first_frame/approve/`. Референсы персонажей — из `refs/` этого этапа, иначе из `characters/approve/` (до двух). Если лица в кадре не видно, положите в `refs/` только нужный файл или выберите `final_h3_768`.

Доска сама следит, чтобы промпт H3 держался превью: если в `body` у `prompt.md` нет фиксированной фразы (`use @vid-1 as a reference`), доска ставит её первой; если нет `required motion guide` — дописывает закрывающую строку в конец (первый кадр и превью обязательны, качество — свободно, губы — заново). Если какой-то реплики из `speech.md` нет в `prompt.md`, H3 не запускается.

Финал Wan получает ещё одну строку в конце промпта эскиза: фон остаётся как на первом кадре, новых людей нет, сзади никто не ходит, двери и окна как есть. В 720×1280 Wan иначе додумывает детали (люди на заднем плане, открывающиеся двери). Подробно: `playbooks/models/minimax_h3.md`, «Фиксированная фраза».

Агент может предложить другой вариант через `suggestedWorkflow`.

## Ещё не проверено

- Апскейл до 1080×1920 (SeedVR2) и интерполяция 16 → 32 fps (RIFE) — не в доске.
- Режим `final_h3` через API MiniMax (облако) — не подключён; гайд по выбору локально / API у пользователя (`minimax_h3_final_render_guide.md`).
- Вариант «финал от базового low-res H3-ролика» (шаблон `create_final_video_using_base_reference`): черновик описания в `playbooks/workflows/drafts/final_h3_base_reference.md`, графа и манифеста нет.

## Критерии приёмки

- Действие, композиция и конец совпадают с утверждённым превью. Финал не придумывает новых событий.
- Первый кадр совпадает с утверждённым первым кадром.
- Лица совпадают с референсами персонажей, одежда — с первым кадром.
- Нет артефактов, которые терпимы в эскизе, но не в монтаже: лишние пальцы, мерцание лица, морфинг одежды, блёстки, скачок в последних кадрах.
- Длительность совпадает с превью.
- Файл в `approve/` один на кадр. По нему наблюдение за кадром (`AGENTS.md`, «Shot watch») считает кадр готовым.
