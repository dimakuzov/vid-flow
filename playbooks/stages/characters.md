# Stage: characters

## Goal
Создать персонажа в нужной одежде и максимально подходящей позе для конкретного shot.

## Inputs
- описание персонажа из cast/scenario
- shot brief
- model playbook для image-модели

## Output
Один файл на персонажа в `output/`, затем approve.

## Approve naming
`{character}_{shotId}.png`  
Пример: `lena_s01.png`
