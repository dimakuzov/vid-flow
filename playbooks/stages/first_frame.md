# Stage: first_frame

Оригинал на русском. Для модели: `playbooks/stages/first_frame.en.md`.

Собрать стартовый кадр. Если в кадре есть утверждённые персонажи и локация, вписать их. Если конкретных персонажей и локации нет, кадр делается сразу, предыдущие этапы не нужны. Промпт: `playbooks/models/qwen_first_frame.md`. Граф сборки из готовых картинок: `playbooks/workflows/first_frame_comfy.md`.

## Без персонажа и локации

В `shot.md` пустые `characters` и `location`, либо пользователь прямо сказал сделать кадр сразу. Не ждать `characters/approve` и `location/approve`. Не создавать эти этапы. Не выдумывать имя человека и название места, которых нет в сообщении.

Картинка собирается по тексту кадра и файлам в `refs/` этого этапа. Результат класть в `output/`, выбранный файл — в `approve/`. Граф вписывания персонажа в локацию для этого пути не обязателен.

## Откуда берутся картинки

Не из сырых баз. У баз другой ракурс и другая одежда.

- Локация: один файл из `shots/{shotId}/location/approve/`. Это image 1.
- Персонаж: `shots/{shotId}/characters/approve/{name}_{shotId}.png`. Доска берёт их по алфавиту имени файла: при `julia_s05.png` и `lena_s05.png` Юля — image 2, Лена — image 3. В задаче агенту номера перечислены в «Images the graph receives».
- Лицо, только для крупного плана: портрет персонажа после персонажей (image 3 для одного человека, image 4 и image 5 для двоих). Доска отправляет его, только если в `prompt.md` есть `face from image N`. Откуда: `refs/{name}_face.png` этого этапа, иначе портрет в `data/characters/{name}/` (`portrait.png`, `portret.png`, `{Name}_portret.png`, `face.png`). Правила: `playbooks/models/qwen_first_frame.md`, «Лицо для крупного плана».

В `refs/` этого этапа кладутся копии этих файлов: `location.png`, `{name}.png`. Ручной approve может обойти проверку upstream, но в граф всё равно идут эти кадры, не `view.png` и не `full_body.png`.

## Контракт кадра

```text
shots/{shotId}/first_frame/
  refs/  output/  approve/
  prompt.md  llm_notes.md  refs.md  workflow.md  status.json
```

`workflow.md` — необязательная заметка.

Варианты прогона лежат в `output/` как `{shotId}_ff_v1.png`, `{shotId}_ff_v2.png` и дальше. Выбранный файл: `approve/{shotId}_first.png`.

Отдельной папки `video/first_frames/` нет. В старых заметках промпты раундов жили в `prompt_qwen21.txt`. Здесь промпт раунда пишется в `prompt.md`.

## Два режима

**Сборка.** image 1 — чистая локация, image 2 и image 3 — персонажи. Так меняют место, размер, позу, направление и число людей.

**Правка.** image 1 — уже удачный кадр из `output/`. Промпт описывает одно изменение. Так правят свет, мелкую деталь, яркость.

Не больше одной-двух правок подряд: фон мутнеет. Если нужно менять позу или размер, вернуться к сборке с чистой локации.

Один персонаж — image 3 не подключать. Два персонажа — оба референса и явные «кто слева, кто справа, куда идёт».

С первого раза обычно выходит один персонаж в простой позе на очевидном месте. Дольше собираются два человека, мелкая физическая деталь и поверхность, на которой стоит персонаж.
