# Global playbooks

Эти документы глобальны для всех серий.

Структура:

- `models/` — как писать промпты под конкретную модель
- `stages/` — что должен сделать каждый этап
- `workflows/` — как настраивать Comfy/cloud workflow

Когда подготовишь свои рекомендации, положи markdown-файлы сюда.
Приложение подхватит существующие файлы и покажет их на странице этапа.
