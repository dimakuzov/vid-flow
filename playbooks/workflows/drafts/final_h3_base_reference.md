# Черновик: финал H3 от базового low-res H3-ролика

Источник: шаблон пользователя `create_final_video_using_base_reference.json` (ComfyUI-Continuity, `MiniMaxH3Creator`). Графа и манифеста на доске нет: нужно решение пользователя (вопросы внизу).

## Что видно в шаблоне

| Поле | Значение |
|---|---|
| `short_edge` | 768, 9:16 |
| refine `template` | `FL2VA` (не `REF2VA`, как у `final_h3`) |
| face pass | включён, canvas 512, denoise 0.45 |
| `models.preview` | `taeh3.safetensors` |
| `chunk_ffn` | false |
| seed | фиксированный |
| LoRA сегмента | все выключены |
| ассеты | пусто: ролик берётся из прошлого прогона (`take`), а не загружается |
| длительность | 7 с |

Инструкция в шаблоне (пересказ): описание брать то же, что у прогона «Create_bas_video_low_res», в референс — ролик оттуда и несколько картинок; меток `@…` не писать, вместо них «man», «woman»; LoRA не использовать.

## Вопросы пользователю

1. Это отдельный путь: сначала low-res ролик делает сам H3 (не Wan), потом финал по нему? Тогда нужен ещё этап или вариант превью на H3.
2. Откуда берётся базовый ролик: `video_preview/approve/` или своя папка?
3. Почему без меток `@img-N` — из-за ошибок рефайнера с номерами картинок?

После ответа: граф (тот же `minimax_h3_creator_api.json` или свой), манифест `final_h3_base` и раздел в `models/minimax_h3.md`.
