# Бриф 06. Пост: озвучка, проект DaVinci, субтитры

Две задачи по очереди: **сначала часть A** (озвучка ElevenLabs и таймлайн для DaVinci Resolve), после приёмки пользователем — **часть B** (субтитры). Детали части A вы уже обсудили с пользователем; этот бриф — где и как работать на доске.

## Перед началом

- Прочитай `AGENTS.md`, затем `docs/contracts/stage-folder.md`, `docs/contracts/comfy-job.md` (раздел про Comfy Cloud — образец платного внешнего API с разрешением) и `docs/contracts/graph-binding.md`.
- Этот Next.js новее твоих знаний: перед правкой Next-кода читай `node_modules/next/dist/docs/`.
- `data/` — реальный проект пользователя. Ничего там не удаляй и не перезаписывай. Все проверки — во временной папке: `DATA_ROOT=$TEMP/frameboard-post`, порт **3476**, `COMFY_URL=http://127.0.0.1:9`.
- **ElevenLabs — платно.** Настоящие запросы — только с согласия пользователя и только через кнопку с галочкой разрешения (как Comfy Cloud). В тестах — поддельный сервер на localhost (образец: `src/lib/comfy/cloud.test.ts`). Ключ — `ELEVENLABS_API_KEY` в `.env.local` (git его игнорирует); ключ вписывает пользователь, не ты.
- Работай в своём worktree от `main`: `git worktree add ../vid-flow-post -b post-voice main`, один раз `npm install`. Коммиты — `git -c core.fileMode=false`, только в своей ветке. В `main` не мержить без согласия пользователя. `data/` не коммитить.
- Перед сдачей: `npm test`, `npx tsc --noEmit`, `npx eslint src scripts` — без ошибок. Новую логику покрывать тестами `node --test` во временной `DATA_ROOT`, `FRAMEBOARD_LOOPS=off`.
- В конце каждой части — отчёт `docs/briefs/reports/06a-post-voice.md` / `06b-subtitles.md`: что сделано, что проверено, риски, открытые вопросы.

## Куда складывать данные

Всё — внутри эпизода, в новой папке `data/episodes/{ep}/post/`:

```text
post/
  lines.json              таблица реплик (A1): строится из speech.md, правится на доске
  voices/{character}/     озвучка персонажа (A2), версиями: v1.mp3 + v1.json (ответ /with-timestamps), v2…
  voices/{character}/current.json   какая версия сейчас в работе
  manifest.json           манифест реплик (A4): id, персонаж, файл, вход/выход в источнике, место на таймлайне
  timeline/{ep}_v{N}.fcpxml   таймлайн для Resolve (A5), версиями; старые не затираются
  subtitles/              часть B
  jobs/                   задания долгих операций (если нужны), по образцу data/comfy_queue
```

Настройки голоса — в библиотеке персонажа, один файл на персонажа: `data/characters/{Name}/voice.json` → `{ "voice_id", "model_id", "voice_settings", "seed" }`. Пишет пользователь (или доска из формы); агент не выдумывает `voice_id`.

## Часть A. Озвучка и проект DaVinci

Порядок и решения — из вашего обсуждения (шаги 1–6). На доске это выглядит так.

**Интерфейс.** Секция «Пост» под таблицей кадров, две карточки этапов: **«Озвучка и проект DaVinci»** и **«Субтитры»** (вторая в части A — заглушка «после озвучки»). В первой карточке:
- таблица реплик (кадр, персонаж, текст, место на таймлайне) с правкой места и ручной подрезки границ;
- голос каждого персонажа: есть ли `voice.json`, текущая версия озвучки, «Перегенерировать персонажа»;
- кнопка «Озвучить» — **только с галочкой «Разрешить платную отправку в ElevenLabs»** на один запуск и с оценкой стоимости (число символов);
- кнопка «Собрать таймлайн» (бесплатно, локально) и ссылка на готовый файл с подсказкой «Resolve: File → Import → Timeline».

**Ответы на открытые вопросы — предлагаемые; подтверди у пользователя до кода:**
1. **Формат таблицы реплик** — `post/lines.json`: `[{ id, shotId, character, text, order, at }]`, где `at` — секунды от начала кадра. Строится из `speech.md` всех кадров по порядку; текст и персонаж — из `speech.md` (правятся там), `at` и подрезка — на доске. Начальное `at`: для кадров со звуком в финале (MiniMax, HeyGen) — по паузам в его звуке (`silencedetect`), для остальных — подряд с небольшим отступом.
2. **fps** — таймлайн 24 fps (большинство финалов 24); Wan-клипы 16 fps кладутся как есть, Resolve подгоняет. Размер кадра таймлайна — уточни у пользователя (финалы 720×1280 / 768×1344 / 768×1376).
3. **Где хранить** — `post/` выше.
4. **Перегенерация одного персонажа без потери правок** — новая версия `voices/{character}/v{N+1}`, старые не удаляются; ручные правки границ и мест хранятся в `lines.json` по `id` реплики (не в Resolve) и переносятся на новую версию, пока текст реплики не изменился. Правки, сделанные внутри Resolve, доска прочитать не может (бесплатная версия, без скриптов) — скажи об этом пользователю и договорись, где доводить границы.

Также проверь: свой звук финалов MiniMax/HeyGen — отдельной (выключенной) дорожкой для сверки или вообще не класть.

## Часть B. Субтитры (после приёмки части A)

Пользователь приложит ComfyUI-воркфлоу, который анализирует аудио и даёт разбивку «какой текст в какие отрезки времени звучит». Он нужен для субтитров и как запасной путь шага 3 части A.

- Сначала изучи воркфлоу и напиши пользователю: какие у него входы и выходы, как он запускается (локальный ComfyUI через очередь `data/comfy_queue` — `enqueueComfyJob`; если только Comfy Cloud — по образцу `target: "cloud"` с разрешением).
- Граф положи в `playbooks/workflows/comfy/`, не правя его JSON; подстановку входов делай кодом или манифестом.
- Результат — `post/subtitles/{ep}_v{N}.srt` (и, если пользователь захочет, дорожка титров в таймлайне). Тайминг — от манифеста части A (место реплики на таймлайне + разбивка внутри реплики из воркфлоу).
- Карточка «Субтитры» в секции «Пост»: запуск, готовый файл, перегенерация.
- Ветка `post-subtitles` от `main` после мержа части A.

## Проверка

- Тесты: таблица реплик из `speech.md` нескольких кадров (порядок, персонажи, `at`); склейка длинного текста через `previous_request_ids` и разбор таймстемпов в границы реплик (поддельный ответ ElevenLabs); резка по середине паузы с запасом (`silencedetect` на сгенерированном ffmpeg-ом тестовом звуке); манифест; таймлайн (валидный FCPXML/OTIO: видеодорожка по порядку, дорожка на персонажа, клипы-отрезки длинного файла); перегенерация персонажа сохраняет ручные правки; без галочки в ElevenLabs ничего не уходит.
- В браузере на порту 3476 с временной `DATA_ROOT` и поддельным ElevenLabs: секция «Пост», таблица, «Озвучить» недоступна без галочки, «Собрать таймлайн» даёт файл.
- Первый настоящий прогон ElevenLabs и импорт в Resolve — вместе с пользователем.
