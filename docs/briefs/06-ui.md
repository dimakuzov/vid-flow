# Бриф 6. Интерфейс

Сначала прочитай `docs/briefs/00-overview.md`, затем `docs/contracts/stage-folder.md` (разделы «Статус клетки» и «API»), `docs/contracts/graph-binding.md` (раздел «Несколько воркфлоу на этап»), `docs/contracts/comfy-job.md` (раздел «Что видит интерфейс»), `docs/contracts/agent-request.md` (раздел «API»).

Ветка `b6-ui`, worktree `../vid-flow-ui`, `DATA_ROOT=$TEMP/frameboard-ui`, порт 3466, `COMFY_URL=http://127.0.0.1:9`.

## Твои файлы (правишь только их)

- `src/components/**`
- `src/app/page.tsx`, `src/app/layout.tsx`, `src/app/globals.css`
- `src/app/shots/**` и новая папка `src/app/e/**` (страницы с эпизодом в URL)

Не трогаешь: остальное `src/lib/**`, `src/app/api/**`, `playbooks/**`. Новые поля проси через отчёт.

## Что уже есть

- Все данные — через `GET /api/episodes/{ep}` (сводка) и `GET/PATCH /api/episodes/{ep}/shots/{shot}/stages/{stage}` (этап). `/api/series` — сводка открытого эпизода. URL медиа уже готовы в `MediaFile.url`.
- `StageDetail` уже содержит: `episodeId`, `shotSummary` (действие кадра из `shot.md`), `state` (фаза, `since`, `error`, `busy`), `workflow` (выбор или `null`), `workflows: WorkflowChoice[]` (`id`, `label`, `description`, `available`, `missing`, `isDefault`), `job: JobSummary | null` (`queuePosition`, `queuedAt`, `submittedAt`, `finishedAt`, `error`, `nodeErrors`, `files`), `agentRequest` (`status` с `running`/`error`, `provider`, `error`, `suggestedWorkflow`).
- Выбор воркфлоу: `PATCH .../stages/{stage}` с `{ runWorkflow: "<id>" }` (пустая строка — по умолчанию). Запуск: `POST .../run` с `{ runWorkflow }`. Отправка агенту: `POST .../agent-request` с `{ message, prompt, refs, workflow /* заметка workflow.md */, runWorkflow, provider }`.
- Провайдеры агента: `GET /api/agent/providers` → `AgentProviderInfo[]` (`id`, `label`, `modes`, `available`, `reason`, `isDefault`). Маршрут делает бриф 5; пока его нет (404) — селектор не показывать.
- Компоненты уже ходят в новые маршруты (`shotApi`/`stageApi` в `stage-workspace.tsx`, проп `episodeId` у `StageCell`) — бриф 2.

## Задачи

1. **Эпизод в URL.** Страницы `/e/{episodeId}` (таблица) и `/e/{episodeId}/shots/{shotId}/{stage}` (этап). `/` — редирект на открытый эпизод (`current_episode.txt` через `scanSeries()`), `/shots/{shot}/{stage}` — редирект на новый путь открытого эпизода. Переключатель в шапке ведёт на URL эпизода; `POST /api/series/episode` вызывать только чтобы запомнить выбор по умолчанию. `SeriesBoard` опрашивает `GET /api/episodes/{ep}`, а не `/api/series`.
2. **Разделить `stage-workspace.tsx`** (~33 КБ): лайтбокс, карточки медиа, refs, документы, история промпта, отправка агенту, запуск, approve, watch → компоненты + хук `useStageDetail` (загрузка, опрос, слияние с несохранёнными правками). Поведение то же.
3. **Опрос и ввод.** Явный флаг «поле изменено локально» вместо сравнения строк; если файл изменился на диске, пока поле правят, — плашка «файл изменился на диске — подтянуть?». Заодно уйдут 11 ошибок eslint `react-hooks/refs` в `stage-workspace.tsx`.
4. **Полоса состояния этапа.** Фаза и время в ней (от `state.since`), позиция в очереди ComfyUI (`job.queuePosition`), текст ошибки (`state.error`, `job.nodeErrors` списком), «Отменить» / «Сбросить ошибку». Фазу брать из `state.phase`, не из `job.status`.
5. **Выбор воркфлоу.** Меню из `workflows` на странице этапа и в меню клетки (вместо переключателя i2v/FLF; в `StageSummary` вариантов нет — меню клетки загружает `GET` этапа при открытии): недоступные — с подписью `missing`; выбор — `PATCH runWorkflow`; «Запустить» и «Отправить агенту» передают `runWorkflow`. Если `agentRequest.suggestedWorkflow` отличается от выбора — показать предложение агента с кнопкой «Переключить».
6. **Провайдер агента.** Селектор рядом с «Отправить агенту» (из `/api/agent/providers`, недоступные — с `reason`), выбор помнить в `localStorage`; статус запроса (`running`, `error` с текстом).
7. **Пустой `prompt.md`.** Новые кадры получают пустой `prompt.md`. Подсказка в поле: «Текст для модели, на английском. Пусто — отправьте рекомендацию агенту». Действие кадра (`StageDetail.shotSummary`) показывать над полем, только для чтения.
8. **Контекст результата (по желанию).** Промпт и seed из метаданных PNG по клику на карточку output (чанки `prompt`/`workflow`), чтение в браузере.
9. **`README.md`**: раздел «Что уже работает» устарел; опиши запуск (`npm run dev`, `DATA_ROOT`, `COMFY_URL`, переменные провайдеров агента из `docs/contracts/agent-request.md`), что фоновые циклы живут в процессе Next, и ссылку на `docs/contracts/`.
