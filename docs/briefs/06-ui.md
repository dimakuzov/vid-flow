## Найденные проблемы

1. **Ошибка типов:** `src/components/board/series-board.tsx:154` — `onClick={reload}`, а `reload` принимает `{ quiet?: boolean }`, получит событие клика. Исправь (`onClick={() => reload()}`).
2. **`stage-workspace.tsx` — 32 КБ в одном файле**: лайтбокс, карточки медиа, refs, документы, история промпта, отправка агенту, запуск, approve, watch. Раздели на компоненты и хук данных этапа (`useStageDetail`: загрузка, опрос, слияние с несохранёнными правками).
3. **Опрос каждые 4 с с логикой «не затирать то, что пользователь печатает»** сделан сравнением строк с последним показанным текстом. Проверь гонки: агент переписал `prompt.md`, пока пользователь редактирует другое поле; пользователь начал печатать во время ответа сервера. Сделай явный флаг «поле изменено локально» и показ «файл изменился на диске — подтянуть?».
4. **Полоса состояния этапа.** Фазы и блокировку бриф 1 сделал минимально. Доведи показ: сколько времени в фазе, позиция в очереди ComfyUI, текст ошибки, «Отменить», выбор провайдера агента (бриф 5).
5. **Контекст результата (по желанию).** Промпт и seed уже лежат в метаданных PNG. Можно показывать их на карточке output по клику (чанки `prompt`/`workflow`).
6. **Зависимость от «открытого эпизода».** Переключатель в шапке переписывает `current_episode.txt` для всех, включая агентов и очередь. После мержа модуля 2 перенеси эпизод в URL (`/e/<episodeId>/...`).
7. В `README.md` раздел «Что уже работает» устарел (кнопка «Запустить» уже не заглушка). Обнови после своих правок.
