# Отчёт 05. Язык интерфейса

Ветка `r3-ui-language` от `r3-test` (`6622aed`). Worktree `vid-flow-r3-lang`. В `main` не мержил, коммита и PR нет.

## Что сделано

- В шапке таблицы и на странице этапа один переключатель EN / RU. Он только пишет язык в `localStorage` (`frameboard.lang`) и меняет подписи. На диск серии, в API, агенту и в запуск ничего не уходит.
- Язык по умолчанию — константа `en` в `src/lib/i18n.ts`. Первый заход без сохранённого выбора — английский. Сервер язык не читает: первый HTML всегда английский, выбор подхватывает браузер.
- Один словарь и один способ взять строку в клиенте: `t(lang, key)` и хук `useT()`. Вторых копий страниц нет.
- Переведены видимые подписи в `src/components/**` и шапке `src/app/layout.tsx`: таблица кадров, страница этапа, импорт, «Пост», диалог новой серии, меню модели и агента, пустые состояния, плейсхолдеры, список горячих клавиш.
- Подписи этапов и статусов на экране берутся из словаря по id. Сами id, маршруты, поля JSON и файлы не менялись. `STAGE_LABELS` и `STATUS_LABELS` в `constants.ts` оставлены: их читают сервер, заметки и тесты.
- Названия воркфлоу, описания из манифестов, тексты `refs.md` / `workflow.md` / `prompt.md`, сценарий, названия кадров, реплики и имена персонажей на экране остаются как записаны.
- Кнопки, которые уже есть в `r3-test`, только переведены. «Запустить» на этапе, «▶ Агент» у кадра и ссылка «FCPXML для Resolve» в «Пост» не добавлялись и не возвращались: они уже были в этой ветке.
- В `series-board.tsx` слушатель клавиш таблицы типизирован как `globalThis.KeyboardEvent`. На `r3-test` `npx tsc --noEmit` уже падал на этой строке. Поведение клавиш то же.

## Риски и что не сделано

- При полной загрузке страницы, если в браузере уже выбран русский, первый HTML всё ещё английский: сервер язык не знает. После гидратации подписи становятся русскими. На проверенной перезагрузке таблицы снимок уже был русским.
- Сообщения об ошибках и успехах из маршрутов API и `src/lib` остаются по-русски и в английском интерфейсе. Так и задано: сервер от языка не зависит, тексты с тестами не трогал.
- Подписи входов графа, кроме «Персонаж …» и «Одежда …», приходят с сервера и остаются как есть. То же для подписей файлов в «Добавить референс из…», если это не заголовок группы.
- Названия и описания воркфлоу — из манифеста, не из словаря.
- Шрифты шапки без кириллицы: русские буквы рисует запасной шрифт системы.
- Окно «Править» в браузере не прогонял.

## Предложения

- Если вспышка английского при перезагрузке мешает, это уже другой механизм, чем `localStorage`: серверу пришлось бы знать язык. В бриф это не входило.
- Подписи входов графа и ответы API можно переводить на клиенте по стабильному id, не меняя текст на сервере.
