## Что нужно

В шапке доски — переключатель языка. Два языка: английский и русский. По умолчанию английский, в том числе при первом открытии, до того как пользователь нажал кнопку. Выбор запоминается в браузере и переживает перезагрузку. Сервер, файлы эпизода и API от выбора языка не зависят.

Переводится только то, что пользователь видит в интерфейсе: подписи, кнопки, заголовки, пустые состояния, подсказки, плейсхолдеры, список горячих клавиш, сообщения, которые рисует страница. Сюда входят таблица кадров, страница этапа, импорт сценария, «Пост», диалог новой серии, меню модели и агента.

Не переводится и не меняется:

- логика, маршруты, имена полей JSON, id кадров, статусы, имена файлов;
- тексты сценария, названия кадров, реплики, промпты, `prompt.md`, `shot.md`, описания картинок;
- плейбуки и тексты, которые уходят в модель;
- тексты ошибок внутри `src/lib`, если на них завязаны тесты. Если такая ошибка показывается на странице, английский интерфейс может оставить её как есть.

Кнопка в шапке только переключает язык. Она ничего не сохраняет на диск, не вызывает агента и не запускает этап.

## Как сделать

Один словарь на два языка, например `src/lib/i18n.ts`, и один способ взять строку в клиентских компонентах. Язык по умолчанию — константа `en`. Запоминание — `localStorage`. Не размазывать пары строк по компонентам и не заводить вторую копию страниц.

Пройти видимые строки в `src/components/**` и `src/app/**`. Не выдумывать новые кнопки и не возвращать убранные («Запустить» на этапе, «▶ Агент» в столбце «Кадр», DaVinci и Resolve в «Пост»).

## Проверка

- Первый заход без сохранённого языка — английский. Переключатель меняет подписи на русские и обратно. После перезагрузки язык тот же.
- Создание кадра, отправка агенту, галка импорта, правка фрагмента — те же запросы, что до перевода. Меняются только слова на экране.
- `npm test`, `npx tsc --noEmit`, `npx eslint src scripts`.
- Отчёт: `docs/briefs/round-3/reports/05-ui-language.md` по образцу в `00-overview.md`.

Не мержить в `main`. Коммит и PR — только если пользователь попросил.
