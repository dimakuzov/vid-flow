## Что нужно

### 1. «Добавить референс из…»

Кнопка у «Референсы» на странице этапа, меню источников:
- библиотека персонажей `data/characters/{name}/` (персонажи кадра сверху, остальные ниже);
- библиотека локаций `data/locations/{id}/`;
- общие картинки `data/references/`;
- `approve/` и `output/` других этапов **этого** кадра;
- `approve/` того же этапа **других** кадров эпизода (типичный случай: тот же персонаж в соседнем кадре).

Выбор — сетка превью, можно несколько. Файл **копируется** в `refs/` этапа (имя сохраняется, при совпадении — суффикс, как `uniqueTarget` в `mutations.ts`), помечается «тронуто пользователем» (`agent_touch.json`, как при загрузке). Список источников и путей — новый модуль `src/lib/series/ref-sources.ts` + маршрут API. `library.ts` не править (зона брифа 01): читать папки библиотек самостоятельно.

### 2. Горячие клавиши

На странице этапа (не срабатывают, пока фокус в поле ввода, кроме `Ctrl+Enter`):

| Клавиши | Действие |
|---|---|
| `Ctrl+Enter` (в поле «Рекомендация») | Отправить агенту |
| `Ctrl+Shift+Enter` | Запустить |
| `A` | Утвердить выбранные в output |
| `←` `→` | Листать картинки в просмотре |
| `Esc` | Закрыть просмотр / меню |
| `?` | Показать список клавиш |

На таблице: `←` `→` `↑` `↓` — выбор клетки, `Enter` — открыть этап. Список клавиш — в одном месте (модуль), подсказка `?` берёт его оттуда. Другие сочетания — только после вопроса пользователю.

### 3. Правка изображения (обрезка и правка моделью)

Кнопка «Править» на картинке в `output/` и `approve/` любого этапа и в просмотре (`image-lightbox.tsx`). Окно правки:
1. **Обрезка** в браузере: рамка, пропорции (свободно, 9:16, 16:9, 1:1, как у исходника). «Сохранить обрезку» — новый файл в `output/` этапа: `{исходное имя}_crop.png` (при совпадении — суффикс). Без ComfyUI.
2. **Правка моделью**: поле «что изменить» по-русски (убрать предмет, сделать ночь, дождь, другой свет) + выбор воркфлоу правки. Текст в английский промпт правки переводит агент (claude, режим text, как на этапах; модель — Sonnet), по плейбуку `playbooks/models/image_edit.en.md` (+ русский): `Edit image 1: <одно изменение>. Keep EVERYTHING else exactly the same: …` — правила уже есть в `playbooks/models/qwen_first_frame.en.md`, раздел «Modes». Доска ставит задание в очередь ComfyUI, результат — новый файл в `output/` того же этапа: `{исходное имя}_edit_v1.png`.
3. **Оригинал не трогается никогда.** У нового файла видно, из чего он сделан (подпись на карточке; хранить связь в `output/edits.json` этапа: `{ file, from, kind: crop | edit, prompt?, workflow?, at }`).
4. **Воркфлоу правки** — отдельная папка `playbooks/workflows/comfy/edit/` (её не читает `loadBindings`, меню этапа не меняется): граф + манифест того же формата, вход `image` — правленый файл. Первый вариант — Qwen Image 2.1 Edit на графе `qwen21_character_compositing.json` с одной картинкой (image 1 — исходник). «Улучшение качества» — **только когда пользователь пришлёт граф** (спросить в чате). Сборка задания — новый модуль `src/lib/comfy/edit.ts`, переиспользуя экспортированное из `binding.ts` (`buildPrompt`, `validateBinding`); нужна правка `binding.ts` — в «Нужно от других».
5. Обрезка и правка — для любого этапа одинаково. Если правленый файл пользователь утверждает — обычный аппрув.
