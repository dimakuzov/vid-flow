# Отчёт по эпизоду. Только чтение, таблица в Markdown

Ты не разработчик доски и не агент этапов. `AGENTS.md`, разделы «Shot watch» и «First useful agent task», к тебе не относятся: входящие не читаешь, `prompt.md` не пишешь, ComfyUI и модели не вызываешь.

Код не менять. `data/` не менять, ничего не удалять и не создавать внутри `data/`. Не мержить ветки, не пушить, не запускать `next dev`.

## Что сделать

По одному эпизоду собрать статистику генерации и отдать её таблицами Markdown.

Эпизод называет пользователь. Если не назвал — папка `data/episodes/` с самым новым временем изменения. В первой строке ответа напиши, какой эпизод взят и почему. `data/current_episode.txt` — это открытый эпизод, не обязательно последний сделанный. Сейчас на диске есть `ep2`, `episode3`, `episode_4`, `teaser`; не выбирай молча, если пользователь уже назвал другой.

Список показателей — сообщение пользователя в этом чате. Считай только его. Не добавляй свои колонки и не выкидывай пункт, даже если следа нет. Пока списка нет — один вопрос «пришлите список» и стоп, ничего не обходи.

## Куда писать

1. Тот же текст в ответ в чате.
2. Файл `docs/briefs/round-3/reports/episode-report.md` в папке `vid-flow`. Это единственный файл, который можно создать. `data/` не трогать.

## Как выглядит ответ

Сначала одна строка: эпизод и из какой папки.

Потом по таблице на каждый показатель из списка пользователя.

Строки — кадры (`s01`, `s02`, …) в порядке номеров. Последняя строка — «Итого». Колонки — этапы в порядке доски: Персонажи, Локация, Первый кадр, Превью, Финал, затем «Всего», если показатель складывается. Число — в ячейке. Если следа нет, ячейка ровно `нет следа`, не ноль и не прочерк. Ноль — только когда ты посмотрел и событий не было.

Под таблицами короткий список «Как считал»: для каждого показателя одно предложение, из какого файла взято число. И список «Этого на диске нет» — какие пункты пользователя нельзя восстановить и почему.

Без советов, что улучшать в пайплайне. Без картинок и без длинных цитат промптов.

## Откуда брать факты

Корень — `data/episodes/{эпизод}/shots/{кадр}/{этап}/`. Этапы: `characters`, `location`, `first_frame`, `video_preview`, `final_render`.

| Что смотреть | Файл |
|---|---|
| Прогоны Comfy: сколько, какой воркфлоу, статус, время, какие файлы получились | `data/comfy_queue/*.json`. Поля: `episodeId`, `shotId`, `stageId`, `workflow`, `status`, `queuedAt`, `submittedAt`, `finishedAt`, `files`, `error`, `target` |
| Последний запрос агенту, не история | `agent_request.json` этапа. Старые запросы туда не складываются |
| Журнал прогонов агента, если его дописывали | `run_log.md` этапа |
| Замечания к кадру | `shots/{кадр}/notes.json` |
| Сколько раз меняли промпт | `prompt_history.json` этапа: число версий. Текущий `prompt.md` в это число не входит |
| Какой воркфлоу выбран сейчас | `run_settings.json` → `workflow`. Истории переключений нет |
| Результаты и утверждённое | имена файлов в `output/` и `approve/`, время файла |
| Обрезка и правка картинки, если уже пользовались окном «Править» | `output/edits.json`: `kind` = `crop` или `edit`, `from`, `file` |
| Пользователь трогал референсы | `agent_touch.json` → `refsTouchedByUser` |

Задание очереди относится к кадру, если `episodeId` и `shotId` совпали. Задание без этих полей, но с `saveTo` внутри папки этого кадра, тоже его. Чужой эпизод не считать.

Файл в `output/`, которого нет ни в одном `files` заданий этого этапа и нет в `edits.json`, — ручная загрузка в output. Файл в `approve/`, которого нет в `output/` этого этапа, — загрузка сразу в approve. Файл в `approve/`, который совпадает по имени с файлом в `output/` или с `files` задания, — утвердили результат прогона, не дозаливали с диска.

«Пересоздавал» — число заданий очереди со статусом `done` или `error` по этому кадру и этапу. `cancelled` и `pending` в это число не входят; их напиши отдельно только если пользователь спросил про отмены. Один прогон персонажей может быть несколькими заданиями (по персонажу) — считай задания, не клики.

Смену воркфлоу посчитать нельзя: на диске только текущий id в `run_settings.json`. В ячейке `нет следа`, в «Как считал» — какой id стоит сейчас.

Время прогона — `finishedAt` минус `submittedAt`, если оба есть. Времени, пока страница была открыта, на диске нет.

Не открывай картинки и ролики. Считай имена, статусы и поля JSON. Секреты и ключи не цитируй.
