# Отчёт: бриф 3, запуск в ComfyUI

Ветка `b3-comfy-runner` (в облаке — `claude/b3-comfy-runner-lepc9m`), от `contracts`.

## Сделано

1. **Раннер на манифестах.** Новый `src/lib/comfy/binding.ts`. Он загружает `playbooks/workflows/comfy/*.bind.json` через `getPlaybooksRoot()`, кэширует по mtime манифеста и графа и проверяет каждый манифест против графа при загрузке. Если ноды или поля нет, ошибка называет манифест, слот, ноду (и класс) и граф: «манифест bad: слот 1: ноды 404 нет в графе g.json». То же для `whenEmpty`, ссылок на входы, `when.input`, регэкспов `unless`.
   Сборка `buildPrompt(binding, graph, ctx)` поддерживает:
   - источники `refs`, `approve:<stage>`, `library:location` и массив источников;
   - `pick` first/newest/all, `min/max`, `uploadAs` (`{shotId} {episodeId} {index} {ext}`);
   - текст из `prompt.md` и `prompt:seconds`;
   - `steps` (`namesTo` с границей слова, которая работает и для кириллицы; `ensure`);
   - `templates` с `when`; строка, где был только плейсхолдер и он оказался пустым, удаляется;
   - `seed: random` — своё число на каждый target;
   - `template`, `whenEmpty.remove` (применяется после всех слотов).
   `stage-run.ts` больше не знает node id: `queueStageRun` = выбор манифеста → `buildPrompt` → задание. Id задания: `<shot>-<manifest>-<ms>`.
2. **`workflows.ts` по манифестам.** Меню идёт по `order`. `available`/`missing` считаются только по картинкам с `min ≥ 1`. По умолчанию выбирается первый доступный вариант. Работают `aliases` и `playbook`. Сломанный манифест виден в меню как недоступный, причина записана в `missing`, запуск отдаёт ту же ошибку. Этап без манифестов (`characters`) получает пустой список, а запуск — ошибку «У этапа characters нет воркфлоу доски…».
3. **Модель получает только `prompt.md`.** `generationText()` и `refusesAngleGraph()` удалены. Если в `prompt.md` есть строка, которая начинается с `Собери `, `Правила: playbooks/`, `Локация:` или `Персонажи:`, запуск падает с ошибкой «prompt.md содержит инструкцию для агента, а не текст для модели: перепиши его или отправь агенту.» Тихого вырезания больше нет. Пустой обязательный `prompt.md` тоже даёт ошибку.
4. **Сверка до/после.** `src/lib/comfy/legacy.test.ts` + `fixtures/`. Задания для 10 кадров сняты старым `stage-run.ts` (коммит `contracts`): location ×2 (refs; библиотека, где «no people» уже есть), first_frame ×3 (1 и 2 персонажа, пустой prompt), video i2v ×2 (с камерой и без), video flf, final i2v, final flf. Prompt хранится как отличия от графа манифеста, seed обнулены. Новый код сравнивается с ними полностью: prompt, uploads, saveTo.
5. **Подробности задания.** Очередь пишет `submittedAt`, `finishedAt` (done/error/cancelled) и `queuePosition`: один `GET /queue` на проход, 0 — выполняется, 1.. — ждёт, `null` — неизвестно. При ошибке пишутся `nodeErrors` (`{node, classType, message}`, текст из `message: details`) и короткий `error` без JSON. Ошибка выполнения из истории (`execution_error`) тоже попадает в `error` и `nodeErrors`. Пока prompt стоит в очереди ComfyUI, таймаут истории не срабатывает: долгое видео больше не уходит в ошибку через 15 минут.
6. **Уникальные имена.** `finishJob` пишет с `flag: "wx"`. Если имя занято, добавляется суффикс `name-2.png`, `name-3.png`… Байты записываются как есть, итоговые имена попадают в `files`.
7. **`run/route.ts`.** Тело `{ runWorkflow }`, старое `{ workflow: "i2v" }` тоже принимается. Пустое тело означает выбор этапа или вариант по умолчанию. Если значение не строка, ответ 400. Формат ответа не изменился.
8. **`scripts/comfy-queue.ts`.** При запуске выводит предупреждение, что вместе с `npm run dev` его не запускают.

## Риски

- Видео (`video_preview`, `final_render`) не запустится, пока бриф 4 не исправит манифесты. Это сделано намеренно: иначе к каждому видео-промпту молча добавлялось бы «Static shot, fixed camera.».
- Кириллические имена в `namesTo` теперь заменяются. Старый `\b` их пропускал. Для латинских имён поведение то же.
- Повторные имена получают суффикс `-N` перед расширением. Если UI или агент ищут файл по точному имени ComfyUI, им нужно брать имя из `job.files`.

## Нужно от других модулей

- **Бриф 4 (блокирует 5 тестов):** в `video_i2v`, `video_flf`, `final_i2v`, `final_flf` поле `unless` = `"\b(camera|…|камер)\b"`. В JSON `\b` — это символ backspace (U+0008), а не граница слова. Нужно `"\\b(camera|shot|static|pan|dolly|zoom|трек|камер)\\b"`, по две правки на файл. После этого `npm test` в этой ветке станет зелёным. По порядку мержа 4 → 3 так и получится.
- Бриф 6: `StageDetail.job` уже заполняет `submittedAt`, `finishedAt`, `queuePosition`, `files`, `error`, `nodeErrors`. Если в меню воркфлоу у варианта `missing` начинается с «манифест …», это ошибка манифеста, а не недостающий вход. Её стоит показать как есть.
- Контракты: ничего расширять не понадобилось.
