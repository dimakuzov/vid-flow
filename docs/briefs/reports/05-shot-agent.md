# Отчёт 05. Агент кадра

Ветка `shot-agent` (поверх `format-abort`: остановка разметки сценария, «Открыто 2»).

## Что сделано

- **`shots/{shotId}/agent.json`** → `{ provider, model, updatedAt }`. Пишет только доска: `src/lib/series/shot-agent.ts` (`readShotAgent`, `writeShotAgent` с проверкой провайдера и модели, `readShotAgentActivity`). Маршрут `GET/PUT /api/episodes/{ep}/shots/{shot}/agent`.
- **Массовые запуски** (`src/lib/series/bulk.ts`): каждый кадр идёт своим агентом. Выбор из меню назначается всем кадрам без агента (`BulkResult.assigned`), у кадров с агентом остаётся их агент. Нет выбора и нет агента — агент доски по умолчанию, без назначения. Пройденное и занятое не трогается, как раньше.
- **«▶ Агент» на кадре** — новое меню `src/components/board/shot-agent-menu.tsx`: «Агент кадра sXX», выбор провайдера и модели (по умолчанию — агент кадра), «Сохранить», «Запустить следующий этап» (сначала сохраняет выбор), «Остановить» (все прогоны агента доски на кадре: `POST /api/agent/runs/stop { episodeId, shotId }`).
- **«▶ Агенты по кадрам» / «▶ Все кадры»** (`bulk-menu.tsx`): агента спрашивают, только если есть кадры без агента («Для N кадров без агента (станет их агентом)»). Если агент есть у всех — «У всех кадров свой агент», только «Запустить на N кадрах». В итоге видно, кому назначен агент.
- **Заголовок кадра**: «Claude Code · Haiku 4.5 — свободен» / «— работает: Локация, с 14:05» / «— ждёт очереди: Локация» / «— ждёт агента в чате: Локация» / «нет агента». `ShotSummary.agent`, `ShotSummary.agentActivity` (`{ stageId, status, since, provider }`: к брифу добавлен `provider`, чтобы отличить ручной режим).
- **Страница этапа**: «Отправить агенту» по умолчанию берёт агента кадра (`StageDetail.shotAgent`). Строка «Агент кадра: …». При другом выборе — галка «Запомнить этот выбор агентом кадра (иначе — только на этот раз)» (`rememberForShot` в POST agent-request; запись только после принятого запроса). У кадра без агента галка по умолчанию включена.
- Мелочи: один запрос `/api/agent/providers` на все меню таблицы (кэш 30 с, раньше — запрос на каждое меню). Хук `useFloatingMenu` общий для меню таблицы; меню у нижнего края экрана открывается вверх.
- Документы: `docs/contracts/agent-request.md` (API, раздел «Агент кадра»), `docs/contracts/stage-folder.md` (строка `agent.json`), `AGENTS.md` (агент не трогает `agent.json`).
