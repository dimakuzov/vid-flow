# Comfy SDK как второй транспорт

Доска может ходить в ComfyUI и Comfy Cloud через официальный `@comfyorg/sdk` (Comfy API v2) вместо прямых HTTP-вызовов. Формат `data/comfy_queue/<id>.json` и правила для агентов не меняются: выбор делает `src/lib/comfy/transport.ts`, реализация SDK — `src/lib/comfy/sdk.ts`. Прямые модули `client.ts` и `cloud.ts` остаются, по умолчанию работают они.

Нужен Node 22+. Пакет в бете (проверено на 0.5.0).

## Запуск локально (ComfyUI + comfy-api-proxy)

SDK не говорит с ComfyUI на `:8188` напрямую, только через прокси.

```bash
pip install comfy-api-proxy
comfy-api-proxy   # перед ComfyUI; порт по умолчанию 8189, настройки — в документации пакета
```

```bash
COMFY_TRANSPORT=sdk COMFY_BASE_URL=http://127.0.0.1:8189 npm run dev
```

`COMFY_BASE_URL` по умолчанию `http://127.0.0.1:8189`. `COMFY_URL` в этом режиме не используется. Ключ для прокси не нужен: доска создаёт локальный клиент без ключа и не передаёт ему `COMFY_API_KEY` из окружения.

## Comfy Cloud

Ключ тот же: `COMFY_CLOUD_API_KEY` в `.env.local`. Клиент облака создаётся с `apiKey`, переменная `COMFY_BASE_URL` на время его создания снимается (для SDK пустой адрес — это Comfy Cloud). `COMFY_CLOUD_URL`, если задан, ведёт на другой стенд.

Правило из AGENTS.md сохраняется: платный прогон уходит только с доски, после галочки «Разрешить платную отправку в Comfy Cloud». Повторных отправок нет.

## Что SDK не умеет, и как это видно на доске

- **Очередь.** В SDK нет чтения общей очереди (список ждущих и выполняемых заданий), поэтому `readComfyQueue()` в SDK-режиме бросает ошибку, `queuePosition` у заданий остаётся `null`, а «потерянное» задание по таймауту не определяется. Если сервис забудет задание, это, вероятно, станет ошибкой чтения (`NotFound`); живьём не проверено.
- **Отмена.** `job.cancel()` документирован только в типах; сигнатуры ожидания в документации нет. Ошибки отмены глушатся, как и раньше.
- **Тип выходов.** Берутся `image`, `video` и `text`. `audio`, `file`, `latent` доска не забирает. Как SDK классифицирует выход Continuity (`mmc_video`), не проверено.
- **Ошибки нод.** Разбор `node_errors` из `details` у `InvalidWorkflow` написан по формату ComfyUI; формат `details` в SDK не описан и живым прогоном не проверен.
- **Имена файлов.** Загрузка идёт через `assets.fromBytes` (по хэшу), имя файла в графе заменяется на дескриптор при отправке. Поэтому подмена имён (`renameUploads`) в этом режиме — no-op: имя остаётся прежним.
- **Адрес облака.** `COMFY_CLOUD_URL` работает через `COMFY_BASE_URL` внутри SDK.
