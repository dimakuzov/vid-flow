# База персонажей

Канонические виды, общие для серии. Shot-вариант собирается в `shots/sXX/characters/` и утверждается как `approve/{name}_{shotId}.png`.

На персонажа, папка по имени из сценария (`lena`, `mark`):

- `portrait.png` — лицо анфас
- `side.png` — лицо в профиль
- `full_body.png` — полный рост, светлый фон

В один проход берётся один образ. Старые варианты в подпапках не подмешивать.

Правила: `playbooks/stages/characters.md`.
